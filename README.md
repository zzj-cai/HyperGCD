# HSI-GCD Base: Model and Training

This is a standalone, training-only release of the non-distilled Base model. It contains the HyperSIGMA-Base spatial/spectral encoders, feature fusion, known-class memory prototypes, and the training dependencies. No files from the original private project are required at runtime.

Official implementation for Hyperspectral Generalized Category Discovery (HyperGCD). The code will be released upon paper acceptance.
